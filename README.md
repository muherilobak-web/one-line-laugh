Entry for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun.

## What it does

`main.ts` writes exactly one funny line — a single sentence of at most 200 characters — to `/output/entry.txt`, with no trailing newline. It uses only Node's built-in `node:fs` module and needs no network access.

## Run

```sh
node main.ts
```

The output file is written to `/output/entry.txt`.
